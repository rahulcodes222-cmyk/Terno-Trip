📧 Email Test Page

How to get emails working:

  1. Option 1 (Easiest): Use Formspree.io - Free form to email
  2. Option 2: Use Resend.com - 100 free emails/month
  3. Option 3: Configure Gmail SMTP (requires 2FA)

Subject: 📞 New Enquiry from [Customer Name] - Terno Trip

Name: [Customer Name]

Time: [Current Time]

Quick Setup with Formspree:

  1. Go to Formspree.io
  2. Sign up (free)
  3. Create a new form
  4. Copy the form endpoint URL
  5. Add to .env.local: 
    FORMPREE_ENDPOINT=https://formspree.io/f/your-form-id
  6. Update route.ts to send to Formspree
